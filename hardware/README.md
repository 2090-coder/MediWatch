# Hardware MediWatch

## Modules V1

- ESP32
- TMP117
- MAX30102
- AD8232
- MPU6050
- GPS UART
- GSM UART
- OLED SH1106 128x64 I2C
- Potentiomètre pour simulation de pression
- Bouton SOS
- Buzzer
- LED RGB

## Alimentation

Le câblage d'alimentation doit être adapté à chaque module. En particulier, le GSM nécessite une alimentation capable de fournir ses pointes de courant. Ne pas supposer que tous les modules acceptent 5 V ou 3,3 V sans vérifier leur documentation.
